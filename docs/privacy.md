# Bhasha Keyboard Privacy Policy

**Effective date: 18 September 2026**

Bhasha Keyboard is an Android input method developed by the Bhasha Keyboard team. This policy explains what information the app processes, why it is processed, and the choices available to users.

## Information processed

The core keyboard processes keystrokes, composing text, language settings, keyboard preferences, emoji/sticker recents, and clipboard entries locally on the device to provide typing, suggestions, editing, and personalization. Bhasha Keyboard does not sell this information, use it for advertising, or log passwords and other sensitive text.

When the user explicitly activates voice typing, the app uses microphone audio for speech recognition. Audio and the resulting transcript may be transmitted to the configured speech-recognition provider, currently Sarvam AI, to provide the requested transcription. The selected language is sent as the recognition language in Transcribe mode. Auto Mix mode may request multilingual detection. Voice typing is opt-in, requires the Android microphone permission, and stops when the user stops the voice session or the inactivity timeout is reached.

When the user explicitly activates optional AI assistant, translation, or search features, the requested prompt, source text, or search query may be sent to the provider needed for that feature. GIF search requests and selected GIF downloads use the GIF provider's public media URLs. A selected GIF or sticker is copied to an app's input field as rich content when the receiving app supports Android `commitContent`; otherwise Android's share chooser is used. The app does not add the GIF URL to the typed message as a text link.

## Storage and retention

Keyboard preferences, local suggestions, recent stickers, and clipboard history are stored locally using Android app storage. Users can clear clipboard history and app data through the app or Android settings. Bhasha Keyboard does not maintain a separate server-side database of typed text. Provider retention is governed by each provider's current terms and privacy documentation; users should review those terms before enabling network-backed features.

## Sharing and security

The app does not share typed text, clipboard content, microphone audio, or provider responses with advertisers or data brokers. Network requests are made only for the user-requested feature. Release signing credentials and API keys must never be committed to the repository.

## Permissions

The app may request microphone access for voice typing and network access for explicitly enabled network-backed features. Android's input-method binding permission is required for the keyboard service. Users can revoke permissions in Android settings; core offline typing remains available subject to Android input-method behavior.

## Children's privacy

Bhasha Keyboard is not directed at children under 13. We do not knowingly collect personal information from children.

## Your choices and contact

Users can avoid network-backed features, disable microphone permission, clear local app data, or uninstall the app at any time. For privacy questions or deletion requests, contact the publisher through the support address shown on the Google Play listing.

## Play Console disclosures

Before publishing, the developer must complete Google Play's Data safety form consistently with the final release, provide the public URL of this policy, disclose microphone and provider data flows, complete the content rating, declare the app as an input method where applicable, and use a unique production upload key. This document supports those disclosures but does not replace the Play Console forms or Google's policies.
